# Documentation Archive

This folder stores historical planning/migration/reference markdown that is kept for audit/history but should not be part of normal agent context loading.

## Archived docs

- `FINAL_MIGRATION_REPORT.md`
- `FINAL_CLEANUP_REPORT.md`
- `COMBAT_SYSTEM_PROPOSAL.md`
- `COMBAT_SYSTEM_SUMMARY.md`
- `FUNCTIONALITY_LOSS_AND_BREAKING_CHANGES.md`
- `FUNDER_CORE_REORGANIZATION.md`
- `MENU_STRUCTURE_REFERENCE.md`
- `PACKAGE_MIGRATION_CHECKLIST.md`

## Usage policy

- Default: do not read archive docs during routine feature work.
- Read archive docs only when:
  - investigating historical decisions,
  - resolving contradictions between current docs/code,
  - intentionally revisiting older migration plans.
